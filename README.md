# PyPractice

A personal learning repository for experimenting with new technologies, tools, and frameworks. This repo contains working prototypes and simple applications to learn and master various Python-based technologies and concepts.

## Overview

This repository serves as a sandbox for:
- Learning new technologies and frameworks
- Building working prototypes
- Experimenting with different architectural patterns
- Refreshing knowledge on core concepts
- Testing integration between different tools

## Project Structure

### API & Web Development
- **`pp_fastapi/`** - FastAPI practice with random number generation endpoints, background tasks, and API versioning
- **`pp_sse/`** - Server-Sent Events (SSE) implementation for real-time data streaming
- **`pp_sockets/`** - WebSocket implementation for bidirectional real-time communication
- **`pp_streamlit/`** - Streamlit UI for testing and demonstrating SSE and WebSocket features

### Communication & Networking
- **`pp_grpc/`** - gRPC practice with Protocol Buffers, including inventory management system with client-server communication
- **`pp_memcached/`** - Memcached caching implementation with Docker Compose setup and monitoring tools

### Core Python Concepts
- **`py_async/`** - Asynchronous programming examples including producer-consumer patterns and pub/sub implementations
- **`py_dsa/`** - Data Structures and Algorithms practice (currently includes linked list implementation)

## Getting Started

Each folder contains its own README with specific setup instructions and requirements. Most projects include:
- `req.txt` or `requirements.txt` for dependencies
- `README.md` with setup and usage instructions
- Working example code

## Technologies Explored

- **FastAPI** - Modern web framework for building APIs
- **gRPC** - High-performance RPC framework
- **Protocol Buffers** - Data serialization format
- **Memcached** - Distributed memory caching system
- **Docker** - Containerization
- **WebSockets** - Real-time bidirectional communication
- **Server-Sent Events** - Real-time unidirectional data streaming
- **Streamlit** - Interactive web UI for testing and demonstration
- **AsyncIO** - Asynchronous programming in Python
- **Data Structures** - Core algorithms and data structure implementations
